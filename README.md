# BikeDemand

## Big Data Project - Citi Bike Demand Analysis

Dự án thuộc học phần Tích hợp và phân tích dữ liệu lớn.

## Mục tiêu

Xây dựng pipeline xử lý dữ liệu chuyến đi Citi Bike trong 6 tháng đầu năm 2026, sử dụng các công nghệ Big Data để:

- Thu thập và truyền dữ liệu qua Kafka
- Xử lý dữ liệu bằng Apache Spark
- Lưu trữ dữ liệu bằng PostgreSQL
- Phân tích nhu cầu sử dụng xe đạp
- Xây dựng mô hình dự đoán nhu cầu
- Trực quan hóa kết quả

## Dataset

Citi Bike Trip Data - 6 tháng đầu năm 2026.

Khoảng dữ liệu chính thức:

- Thời gian: 2026-01-01 → 2026-06-30
- Số chuyến sau làm sạch: 415,708
- Số cột: 13

Dataset thực tế không được commit vào Git repository.

## Architecture

Current infrastructure:

- Apache Kafka
- Apache Spark
- PostgreSQL
- Python
